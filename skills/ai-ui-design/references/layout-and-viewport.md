# 布局与视口验证 (Layout & Viewport)

## 截图精准还原 (Pixel-Accurate Reproduction)

当任务是依据用户提供的截图或设计稿进行精准还原时：

- **基线锁定**：首先明确参考图的逻辑视口尺寸（如桌面 1440×900，移动端 390×844）。图像物理像素不等于逻辑视口，若无法确定需明确做出合理推断并说明假设。
- **对齐网格与几何拆解**：
  1. 测量主区域比例关系（侧边栏宽度、主内容栏边距、多列卡片间隙）。
  2. 提取共享对齐线：标题基线、输入框左对齐线、操作按钮垂直中轴。
  3. 测定字阶与行高：标题、正文、辅助标签的相对字号与行间距。
- **禁止自行发散**：在精准还原任务中，以参考图为绝对视觉基线，禁止擅自发散新风格或私自修改主色调与排版结构。
- **合理补齐未定义状态**：对于参考截图中缺失的交互状态（悬停、按下、禁用、错误提示）与窄屏响应式重排，根据内容功能合理补齐，并明确标注"合理延展部分"。

## 多设备视口验证重点

- **水平无溢出**：任何屏幕宽度下，页面严禁出现非预期的全局横向滚动条。
- **移动端安全区与触控热区**：
  - 严格适配移动端安全区域（`env(safe-area-inset-top)` / `bottom`）。
  - 可点击按钮与可操作热区尺寸不小于 **44×44 pt**。
  - 核心操作栏或悬浮提交按钮不能被虚拟键盘、底部导航条遮挡。
- **高密度与极端字长测试**：
  - 用超长姓名或极端数值测试标题与表格单元格，确认布局自适应折行或优雅截断，不挤破相邻容器。
  - 真实视口下核对字号与行高：拒绝靠 9–11px 的不可读微型文字假装"精致"。
