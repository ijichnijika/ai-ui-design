# 视觉素材与多模态资产 (Media)

## 把资产作为设计起点

好的资产可以承担整个页面的情绪、对象识别或信息重心。先问"如果只保留一张图、一个标题和一个动作，哪张图值得占据这个位置"，再决定是否需要更多模块。不要把资产理解为布局完成后填进去的装饰。

跟随设计北极星决定图像的主体、视角、尺度、光线、颜色、材质和留白。页面的字体、背景、边缘处理与运动从这张图建立呼应；也可以通过一个受控的反差突出主动作。统一是共享视觉逻辑，不是对所有图片套同一个滤镜。

资产要成为结构，而不是装在盒子里的插图：让它跨过版面的分界、占满首屏，或者和文字叠在一起。页面可以是一个完整的世界，而不是"一张页面配一张图"。

## 主动资产生成与凭据管理

- **内置工具主动调用**：若宿主环境具备内置图像生成能力（如 `generate_image`），智能体必须主动调用，自动生成高精 3D 实体、微观材质与主视觉资产，严禁偷懒使用纯 CSS 伪拟态。
- **能力缺失时的凭据索取与物理隔离**：若宿主无内置工具且设计确需图像资产，主动向用户说明并请求 API Key。获取的 Key 必须严格保存于项目根目录的 `.env.agents`（并立即检查确认加入 `.gitignore`），仅在本地构建脚本中读取，绝不写入前端业务代码或提交至版本控制。
- **界面文字可编辑**：文字、按钮、表单、数据标签由原生 DOM 表达，生成的素材仅放在明确容器或背景层中，不把带文字的完整图片作为可交互成品。

## 生成视频与三维微质感路径

### 1. 循环悬浮微动效与背景抠像 (Video Matting)
- **避免边缘偏色与绿边**：对于玻璃、水晶、液态等需要折射与透光的物体，**先在最终页面的背景色上生成画面**，让环境反射与投影烘焙进素材，再用蒙版抠像去除背景。若直接在纯绿幕上生成再抠像，玻璃折射会残留难以消除的绿边。
- **跨越结构边界**：导出带透明通道的 WebM 或透明序列帧，将透明素材放置在两个色块或卡片的分界线上，打破矩形框的沉闷感。

### 2. 关键帧随动交互 (Scroll Scrubbing)
- **电影级叙事**：用图像模型分别生成状态 0（初始状态）与状态 1（终态）。
- **物理插值**：调用视频模型推理出中间过渡片段（2–3 秒）。
- **前端绑定**：将页面滚动百分比或拖动进度线性映射到视频的 `currentTime`，实现类似高端硬件拆解与展开的平滑随动。
