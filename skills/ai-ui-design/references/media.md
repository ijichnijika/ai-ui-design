# 素材与生成资产

## 资产是设计起点

先问："如果只保留一张图、一个标题和一个动作，哪张图值得占这个位置？"再决定是否需要更多模块。资产在布局之前定下，页面围绕它排。

图像的主体、视角、尺度、光线、颜色、材质和留白跟随北极星；页面的字体、背景、边缘处理与运动从这张图建立呼应，或用一处受控的反差突出主动作。统一是共享视觉逻辑，不是给所有图套同一个滤镜。

让资产成为结构：跨过版面分界、占满首屏、和文字叠在一起。页面可以是一个完整的世界，而不是"一张页面配一张图"。

## 生成资产与密钥

真实材质、玻璃折射、金属反光、3D 主体是 CSS 伪拟态的真实度上限，也是廉价 AI 味的主要来源。这类视觉交给生成资产：

1. **宿主有生图工具**（如 `generate_image`）：主动调用，产物存入项目资源目录。提示词写法见 [配图](imagery.md)。
2. **没有，且设计确需**：向用户说明需要什么资产、为什么，并请求一个临时 API Key：
   > 这个设计需要生成 [资产描述]，当前环境没有生图工具。请提供临时 API Key；它只存放在本地 `.env.agents`，仅供本次素材渲染，不写入业务代码、不进版本控制。
3. **密钥隔离**：写入项目根目录 `.env.agents`，并确认它已在 `.gitignore` 中；由独立的本地脚本读取密钥、生成并落地为静态文件。前端代码只引用生成好的文件。

文字、按钮、表单、数据标签始终是原生 DOM；生成素材只放在明确的容器或背景层。

## 视频资产

### 循环悬浮主体（抠像）

适合 Hero 位的旋转晶体、解构机械、液态折射体。

1. 用视频模型生成主体在**页面最终底色上**无缝循环运动的片段。玻璃、水晶、液体会把背景折射进去，在绿幕上生成会残留抠不掉的绿边。
2. 抠像去除底色，导出带 Alpha 的 WebM 或透明序列帧。
3. 以 `<video autoplay loop muted playsinline>` 放在两个色块或区块的分界线上，打破矩形框。

### 关键帧随动（Scroll Scrubbing）

适合产品详情、硬件拆解、步骤引导。

1. 生图得到状态 0（收拢）与状态 1（展开）。
2. 把两张图作首尾帧，用视频模型插出 2–3 秒过渡。
3. 滚动或拖动进度线性映射到 `currentTime`：

```ts
const progress = Math.min(Math.max(scrollOffset / totalDistance, 0), 1);
video.currentTime = video.duration * progress;
```

滚动叙事的节奏规则见 [动效](motion.md)。
