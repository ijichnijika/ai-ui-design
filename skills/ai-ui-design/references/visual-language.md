# 视觉语言

## 从整体到局部

先查看信息焦点、构图和内容密度，再调整空间、排版、色彩与细节。前一层已经解决问题时，不为显得精修而继续添加样式。

每次修改能说明：哪个可见元素、哪种关系存在问题、调整什么、期待改善什么。源码检查可以证明样式不一致，不能单独证明画面更好。

## 焦点、空间与去容器化

- **主次鲜明**：每个任务区域有可辨认的主信息或主动作，辅助信息通过尺度、字重、对比或位置退后；不用多种强强调同时争夺注意力。
- **留白建构**：同类关系保持同类间距，组内更紧、组间更松。先用对齐与留白建立结构，再判断是否需要容器或分隔线。
- **去容器化（De-containering）**：先把内容直接放在画布上，通过对齐、字号和留白组织。容器只在确有分组、选择、背景对比或操作边界时出现；绝对禁止把页面、模块、条目和条目说明逐层套成卡片（卡片嵌套深度严格不超过 1 级）。
- **分隔线克制**：每条线只做一件事。同一处分隔不叠双线、单线再加一个框；留白已经分开的地方不再补线；不要每个层级都画一遍线。线本身是风格的一部分时照样保留，只删重复的那些。

## 字体与排版紧致度

- 按标题、正文、辅助信息、标签和数据建立文字角色。角色稳定，层级有足够区别；实际内容长度决定换行和空间。
- **排版紧致度（Typographic Tightness）**：通过克制的字号、严格的行高与等宽数字排版，传递精密、现代、耐看的高级工业质感。

### 可读性是交付门槛

字号与行高在真实视口、实际字体和 100% 阅读尺寸下判断：
- **正文标准**：阅读型页面的中文正文通常从 16–18px 起步，产品界面正文 14–16px，高密度专业工具可到 13–14px；正文无单位行高 1.6–1.75；操作文字通常 14–16px。
- **标题行高**：多行中文标题通常先用 1.2–1.35 的行高，按真实字形检查。不把标题高度固定为单行，不用负外边距挤压后续内容。展示字确需更紧时，必须看过每个支持视口的实际换行并确认字形不碰撞。
- **中文断行控制**：`text-wrap: pretty` 或 `balance` 只能减少孤字，不能消除。数字和单位（38 秒、47 分钟）、固定词组用不换行包裹；首屏说明、页边批注这类短段落按语义手动断句。行末只剩一两个字，或者词被拆到两行，都算缺陷。

### 示例数据要像真的

示例数据会暴露模板感，即使视觉层已经很好。
- **坚决避开**：整数指标（1,000 位用户、+10%）、张三李四和示例公司、每条都是"2 小时前"、写着"标题""描述"的占位字、页面上反复出现的"了解更多""立即开始"。
- **真实数据特征**：1,238 位用户、+1.83%，时间有"刚刚""昨天 16:12""3 月 14 日"；名字有长有短，顺带验证长名字的排版。按钮说出具体动作，例如"保存草稿""周二发送"。
- **共用场景**：一页上有很多演示时，让它们共用一个具体的虚构场景：同一个产品、同一批人、同一组文件和数字，演示之间互相呼应。

## 色彩与表面

- **语义明确**：颜色按文字、背景、动作、选中与状态等含义使用。品牌色与语义状态可以共存，但不能只靠颜色区别重要状态。
- **全局色彩收敛**：全局主视觉强调色不超过 1 种；避免每张普通卡片都使用不同的强调色、重边框与重阴影。
- **去浮夸发光**：配色做两个自检：去掉所有发光和模糊后，配色是否还成立；能否说出一个用类似配色的成功产品或出版物。
- **色温微调**：表面层级优先用色温和色相的轻微偏移来区分，而不只靠粗暴明暗；背景用带一点温度的中性色。
- **质感按调性取用**：
  - 精致端：表面的高光、层次柔和的阴影、细微冷暖交叉色、细线分隔。
  - 粗粝端：手工和印刷留下的痕迹，从方向的生成引擎里找，不套固定道具。

## 控件与图标选型

同一界面维持一致的图标语言、光学大小与文字对齐。通用图标优先使用成熟资源；特殊品牌插图单独制作，不为每个标题机械添加图标。

陌生图标配可见文字；纯图标按钮仍需可访问名称。箭头符号有含义：↗ 表示打开新页面或外部链接，提交、检查这类原地动作不用它。

### 图标库选型与规则

模型的默认是 Lucide 或 Heroicons：24px、2px 描边、圆头端点。不要每个方向都无脑套用同一套。图标是设计身份的一部分：

| 风格气质 | 推荐图标库 | 特点 |
| --- | --- | --- |
| 精致、编辑、杂志感 | Phosphor (Thin/Light), Iconoir | 极细描边，配高质感无衬线或衬线 |
| 工业仪器、企业级数据工具 | Carbon, Material Symbols (Sharp), Radix Icons | 直角端点、网格严密；Radix 专为 15px 紧凑界面设计 |
| 消费级、友好圆润 | Phosphor (Fill/Duotone), MingCute | 圆角端点，双色或微胶囊填充 |
| 中文密集型业务产品 | IconPark, Remix Icon | 覆盖极广；IconPark 支持动态描边粗细与端点调节 |
| 像素、游戏、极客工具 | Pixelarticons | 原生像素点阵 |
| 品牌标志与生态 | Simple Icons | 纯正官方矢量标识 |

- **一个产品只用一套**：统一画布尺寸与描边粗细。
- **粗细跟字重走**：细字配 1–1.5px 描边，粗黑体配 2px 以上或实心。图标尺寸约为字号的 1–1.25 倍。
- **能用字符就不用图标**：在编辑类或极简界面中，优先使用文字与符号本身：`→` `↗` `※` `§`、编号、缩写。只在能显著加快视觉扫描的地方使用图标。
- **自包含小样内联 SVG**：自包含小样只内联用到的 SVG，不随意引用未固定的外部 CDN 字体。
