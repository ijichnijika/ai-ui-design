# 动效手感与界面过渡 (Motion)

## 先问值不值得

加动效前先问：**如果需要手写一周才能做出来，还值得做吗？** 模型让动效代码生成变得廉价，但随意的滚动淡入、无目的视差和装饰性循环都会增加认知负担。每个动效都应承担明确的反馈、连续性或品牌表达任务。

## 实体手感与参数映射

动效的手感从方向的材质和调性推出，用"动作 + 物理实体"来命名和选择参数（弹簧刚度 Stiffness / 阻尼 Damping）：

| 动作 | 实体参照 | 刚度 / 阻尼 | 适合场景 |
| --- | --- | --- | --- |
| **咔嗒 (Snap)** | 磁铁吸合、卡扣、拨动开关 | 350–400 / 10–15 | 按钮点按、开关切换、下拉展开 |
| **滑入 (Glide)** | 气压闭门器、抽屉阻尼 | 250–300 / 20–25 | 底部浮层面板、抽屉、折叠卡片 |
| **流淌 (Flow)** | 浓缩液滴、雾气弥散 | 150–200 / 30–40 | 页面主视觉出现、宏观背景过渡 |
| **砸落 (Drop)** | 锤击打模、重物落桌 | 400–500 / 5–10 | 确认选择、任务完成的终结反馈 |
| **漂浮 (Float)** | 氦气球微摆、悬浮晶体 | 100 / 25 | 核心 Hero 资产待机循环 |

- **过冲控制**：整页、大面板过冲幅度不超过 1–2%，防止整个视口晃动；徽章、勾选标记等小物件可有 10–15% 弹性。
- **重材质与轻材质**：重材质（金属、石材、硬件控制台）偏短促坚决的咔嗒与砸落；高频操作严禁使用拖泥带水的长动画。

## 时长与幅度规范

| 交互对象 | 推荐时长 | 设计要点 |
| --- | --- | --- |
| **按钮、开关、选中态** | 150–300ms | 按下缩放至 0.96–0.98，按下瞬间立即响应（~80ms），松开弹回 |
| **下拉菜单、气泡提示** | 180–250ms | 从触发点方向展开，缩放从 0.96 开始，不从 0 突兀放大 |
| **侧边栏、抽屉、面板** | 250–400ms | 依据位移距离定；滑入用减速，滑出用加速（时长为进入的 60–70%） |
| **视图与整页切换** | 350–500ms | 严禁超过 500ms，否则会产生明显的卡顿等待感 |
| **卡片悬停微动** | 150–200ms | 悬停上浮 2–4px，阴影微弱加深；**位移严禁超过 8px**，否则显得轻浮劣质 |

## 界面过渡规范

- **连续性（共享元素）**：用户点击的项目就是下一屏的主角。从列表进入详情，被点条目平滑放大为详情容器，其他元素淡出；返回时反向收拢回原位。
- **形态变形不做重叠交叉淡化**：切换视口、筛选或展开卡片时，内容是同一个对象，仅尺寸与布局发生改变。直接通过几何外框变形动画完成过渡，不要把两张图交叉淡入淡出造成鬼影重叠。
- **选中指示底板滑行**：分段控件（Segmented Control）、标签页与菜单项，使用同一块底板滑块滑向新目标，而不是旧项瞬间熄灭、新项突然点亮。
- **动画随时可被打断**：连续快速连击时，动画必须能从当前物理位置立即响应新动作，严禁锁死界面或跳回起点重新播放。

## 滚动叙事 (Scroll Scrubbing)

- **一镜到底**：将长页滚动视为摄影机运镜推拉。主角贯穿始终（推近看微观芯片、拉远看整体机箱）。
- **停下来再展示文字**：每个关键分镜留一段静止区间，文字在停顿时出现，避免边剧烈运动边让用户阅读。
- **无状态反向播放**：每一帧状态仅由当前滚动进度绝对解算，向上反向滚动时必须自然倒放，不劫持用户的系统原生滚动阻尼。

## 动效验收

- **慢速排查法**：在浏览器开发者工具中将动效放慢至 10% 播放，查看是否存在重影、突兀跳动或元素从错误坐标闪现。
- **可访问性降级**：必须遵循系统的 `prefers-reduced-motion: reduce` 设置。当用户开启减少动效时，所有过渡与变形直接瞬间到位，禁用视差与循环浮动。
