# 风格对比页 (Style Explorer)

用内置 [模板](../assets/style-explorer.html) 展示实际小样。外壳参照专业选片工具，采用无色相的浅灰画布和系统字体，让作品本身最突出，也便于判断颜色。它只承担比较和挑选的功能，不带风格倾向，也不作为候选的参考。

并排视图只负责比较画面：每个方向等大排列，作品下方显示编号、名称、色条和"选择"，再加两行以内的北极星。色值、字体和特征放在单张查看的侧栏里。模板负责并排与单张查看、候选筛选、统一视口、实际尺寸、选择即复制与备注；每个候选在独立框架中渲染，其 CSS 不影响其他候选和外壳。

## 交互体验

- **并排与单张**：默认并排且等大，保证比较公平。点击任一画面进入单张查看：画面从卡片放大到主区域，右侧栏滑入展示完整说明；键盘 `←` `→` 左右平滑滑动切换方向，`P` 选定，`Esc` 缩回并排。
- **动效手感**：分段控件和方向列表用滑块移动表示当前项，切换视口、筛选和缩放时外框直接变形，不做叠影；选定时标记弹出确认。
- **可操作性**：HTML 小样默认不执行非安全脚本；自己写的轻量交互小样可标记 `"interactive": true` 运行内联交互；运行中的完整本地项目可使用 `"kind": "url"` 实时挂载。

## 准备输入与 Manifest 规范

在任务目录放置 `manifest.json` 和候选文件：
- HTML 候选为带 `head` 的完整文档，CSS 写在页面里。
- 图片、字体和视频用相对路径引用任务目录里的文件（例如 `img/hero.webp`），生成器会自动内嵌。
- 候选源文件必须位于 manifest 所在目录或子目录。

`manifest.json` 结构规范：

```json
{
  "schemaVersion": 1,
  "project": "<项目名称>",
  "brief": "<所有候选共同表达的内容与主要任务>",
  "round": "01",
  "candidates": [
    {
      "id": "variant-a",
      "name": "博朗工业控制台",
      "concept": "1980年代实体仪器质感，高密度紧凑数据呈现",
      "typography": "DIN 2014 展示，JetBrains Mono 数据，Inter 正文",
      "palette": ["#1c1d1f", "#e6e8eb", "#ff5500"],
      "traits": ["1px冷白分割线", "无圆角无阴影", "实体冲压按钮"],
      "kind": "html",
      "source": "candidates/variant-a.html",
      "interactive": true
    },
    {
      "id": "baseline",
      "name": "当前线上版本",
      "concept": "作为比照的存量设计基线",
      "typography": "系统默认无衬线",
      "palette": ["#ffffff", "#2563eb", "#64748b"],
      "traits": ["常规卡片网格", "左右分栏"],
      "kind": "image",
      "source": "candidates/baseline.png",
      "baseline": true
    }
  ]
}
```

### 候选类型说明

1. **普通 HTML 静态候选 (`kind: "html"`)**：作为视觉样本展示，不执行复杂脚本。
2. **可操作原型候选 (`kind: "html"`, `"interactive": true`)**：允许执行内联 JS 代码，支持点击试玩，对比页中会自动注入内存版存储隔离垫片。
3. **本地开发服务器运行候选 (`kind: "url"`)**：指向本机 dev server（如 `http://localhost:5173/?variant=a`），在 iframe 中实时运行完整应用与响应式排版。
4. **图像候选 (`kind: "image"`)**：支持 PNG、JPEG、WebP 渲染截图。
5. **基线版本 (`"baseline": true`)**：当前线上或存量版本，会自动固定排在第一位并标记为"现状"，方便各方案进行对照。

## 生成和打开

确认本地具备 Python 3.10+ 环境，运行内置生成脚本：

```bash
python3 <skill>/scripts/build_explorer.py <任务目录>/manifest.json --output <任务目录>/style-explorer.html
```

- 生成器会将所有素材、图片和样式单文件内嵌，输出完全便携、可离线直接用浏览器双击打开的单一 HTML 文件。
- 默认拒绝覆盖；若需强制更新本轮对比页，显式添加 `--force` 参数。

## 查看与用户反馈收集

1. **同屏比较与切换**：在桌面（1280×900）或手机（390×844）视口下并排比较明暗块面分布。
2. **单张 100% 验收**：进入单张查看，使用"实际尺寸 100%"检查真实字号、中文字体排版与操作按钮边界。
3. **DOM 元素点选与实时位置批注**：点击顶栏的“点选标注”按钮开启标注模式。鼠标悬浮任意候选元素呈现虚线高亮与十字准星，点击目标元素将在其位置实时唤起浮动备注卡片（自动提取标签、CSS 选择器路径与文本片段）。用户输入修改意见后可：
   - **写入备注并复制**：自动将结构化元素标注注入全局备注，同步触发剪贴板复制；
   - **复制此项**：仅复制当前选中元素的微观修改指令。
4. **选择即复制**：用户在对比页中点击"选择"时，会自动将选中的方案名、轮次和用户备注复制到系统剪贴板。用户直接将该文本粘贴回对话，Agent 即可无缝获取用户的决策。
