# 专业术语词典 (Glossary)

- **AI Tells (AI 味特征)** — 大语言模型因受统计平均与 RLHF 强化训练影响，在界面生成中高频出现的不良视觉惯性，包括泛滥的蓝紫弥散发光、多层卡片嵌套与生硬的自定义控件等。
- **Ambitious Prompting (野心提示词)** — 引入实体物理世界、经典硬件设计或前卫艺术流派等高反差隐喻，向智能体下达具备极高风格张力与严苛负面约束的提示策略。
- **Background Matting (视频背景蒙版抠像)** — 利用计算机视觉分割算法，将视频大模型生成的动态素材去除纯色或环境底色，生成高质量透明通道循环动效的技术。
- **Committee Design (委员会设计)** — 没有单一且坚定的审美主张，为迎合所有利益相关者偏好而相互妥协、最终产出的平庸、安全但缺乏灵魂的设计形态。
- **De-containering (去容器化)** — 摒弃用圆角边框圈住所有信息的习惯，利用排版字阶、严格网格与留白节奏自发划分信息层级的现代布局技法。
- **Double Diamond for Agents (智能体双钻石模型)** — 将传统设计双钻石流程重构为适配 AI 协作特性的三阶段闭环：发散探索（Discover）、深化确立（Define）与克制交付（Deliver）。
- **External Entropy (外部熵)** — 来自模型推理体系之外的真随机性输入，通过向系统注入不可预测因子打破概率均值。
- **Image Generation Enrichment (图像生成多模态增强)** — 在传统代码生成流中融合图像生成模型，用于产出具备物理真实感的 3D 资产与复杂材质。
- **Keyframe Scrubbing (关键帧随动擦除)** — 将用户连续交互（如页面滚动、触摸滑动手势）精确映射至视频序列帧播放进度的交互架构。
- **Next-Token Trap (下一个 Token 陷阱)** — 因大模型逐词预测概率机制而导致的设计决策趋同现象；模型每一步均选择大概率安全词，累积后必然产出平均化俗套设计。
- **Native Platform Resonance (平台原生共鸣)** — 严格遵循目标操作系统（如 Apple iOS/macOS HIG）的控件规范与行为直觉，使界面具备极高的一致性与信任感。
- **Predictable Envelope (可预测区间)** — 模型在常规宽泛指令下最容易落入的统计概率高发区，代表绝大多数未经深度调校的平庸 AI 输出。
- **Ruthless Subtraction (残忍删减)** — 一种坚决做减法的高阶审美约束，主动剥离所有不创造实质业务价值的修饰性视觉元素，使核心内容自然凸显。
- **Stateless Critic (无状态视觉裁判)** — 独立于前端编写智能体的设计审查子智能体，仅依靠浏览器真实全保真渲染截图评估品质，彻底规避代码实现偏见与历史对话干扰。
- **String Seed of Thought (种子字符串思维链)** — 通过外部随机字符串促使模型展开多维度的非同质化设计演绎的启发式技术。
- **Style Explorer (风格对比页)** — 一种单文件便携的离线 HTML 工具，支持桌面与移动端同屏并排比对多个设计候选小样，并提供选择即复制机制。
- **Typographic Tightness (排版紧致度)** — 通过克制的字阶、考究的行高比例与高密度的无衬线/等宽排版，赋予界面精密、现代、耐看的高级工业质感。
