# 实操设计模式库 (Patterns)

## Pattern 1: 外部熵种子字符串注入 (String Seed of Thought)

**When to use**: 需要针对同一个产品或页面，一次性发散出数套风格完全迥异、打破默认蓝紫套路的高质量设计方案时。

**How**:
1. 执行 Shell 命令生成 32 位随机十六进制字符串：
   ```bash
   SEED=$(openssl rand -hex 16)
   ```
2. 向主智能体下达结构化指令：
   ```text
   我需要为 [产品名称/功能] 设计一套极具辨识度的全新视觉方案。
   请严格遵循以下规则：
   1. 你的外部灵感种子是：${SEED}
   2. 请深入解析该种子的字符节奏与数值特征，并将其投射为一套自洽的设计规范（包含：主副调色板、网格对齐逻辑、字重层级比例、核心视觉隐喻）。
   3. 运用顶级设计判断将其落地为功能完备的前端界面。
   4. 严禁在界面渲染或文本中透露该种子字符串。
   ```

**Trade-offs**:
- 优点：彻底阻断模型滑向默认的"安全公约数"，每一轮生成的方案具备真正不可预测的独特性。
- 代价：部分极端种子可能使模型走向过于前卫的探索，需结合人工筛选或 Critic 审查门禁快速收敛。

## Pattern 2: 无状态 Critic 截图审查回路 (Stateless Critic Loop)

**When to use**: 原型开发完成或处于迭代中，需要持续将设计水准拉升至国际顶尖工作室标准，且防止编写代码的智能体自我妥协时。

**How**:
1. 捕获当前设计的全保真渲染截图，并准备 3-4 张该风格领域的专业级商业参考设计图作为视觉基准（Moodboard）。
2. **主动确认评审模式**：在调起子智能体前，主智能体必须主动向用户确认评审深度：
   - **严格达标模式**：严格以 $\ge 9$ 分为通过门禁，未达标则根据整改清单修改并重新提审，最多迭代 3 轮；
   - **单轮诊断模式**：仅执行 1 轮全面深度审查，输出差距诊断与 3–5 项具体修改建议，主 Agent 吸收后直接修正交付。
3. 调用 `invoke_subagent` 调起 `design_critic`（推荐选用 `Model: "pro"`，严格单向隔离代码与会话上下文）：
   ```json
   {
     "Subagents": [
       {
         "TypeName": "design_critic",
         "Role": "UI Design Critic",
         "Model": "pro",
         "Prompt": "请对当前界面截图 [待审截图路径] 进行无状态专业审查。附参考基准 [参考图路径1, 路径2...]。\n\n审查规约（严格遵守）：\n1. 对照参考基准评估整体美学方向，设想国际顶级设计工作室（如 Apple / Pentagram）会如何执行该风格，对比指出当前设计的核心差距。\n2. 兼顾宏观与微观：既评估整体构图张力、流向与负空间节奏，又深究排版紧致度、边距网格与微观细节。\n3. 严查并严惩过度雕琢与 AI 模板特征（泛滥发光渐变、多层圆角卡片嵌套、通用图标、空洞排版）。\n4. 提供紧凑、精炼、高度具体且具执行力的 3-5 项修改清单，拒绝模棱两可的散文空话。\n5. 保持大胆有主见（Bold & Opinionated），给出 1-10 分的绝对客观评分。"
       }
     ]
   }
   ```
4. **主智能体收敛控制原则（严禁泄露给 Critic）**：
   - **严格达标模式**：主智能体内部持有终止判定，仅当评分 $\ge 9/10$ 或已达 3 轮上限时停止循环；
   - **单轮诊断模式**：第 1 轮结束后直接根据修改建议修正代码并交付，不打转迭代；
   - **绝对不要将任何及格门槛写入 Critic 的提示词中**，以防诱导 Critic 放水或滋生评分通胀；
   - 多轮迭代中对 Critic 使用**完全相同的提示词**，确保评分具有稳定的基准可比性。

## Pattern 3: 前期人机共创与方向探索模式 (Human-in-the-Loop Exploration)

**When to use**: 项目初期、需求模糊或处于 Discover（发散探索）阶段。**强制人机协同与小样比对，严禁 AI 单向闭门启动全站工程重构**。

**How**:
1. **前期自主重构禁令**：在此阶段，智能体不得直接启动正式重构，必须将精力聚焦在双向交互与轻量级探索小样上。
2. **Turn 1: 概念抛砖与广度激发**：
   - AI 主动列出 6-8 个大跨度、具有极端视觉张力的概念清单，刻意省略实现细节（如：博朗工业仪器、瑞士网格档案库、等距 3D 微缩工坊...）。
3. **Turn 2: 感官引导与雷区排查**：
   - AI 引导用户注入个人体感偏好：
     - *物理触感*：按钮是清脆阻尼机械感，还是无缝平滑液态感？
     - *材质光影*：是粗粝微噪点哑光，还是高通透玻璃折射？
     - *负面约束*：明确排查哪些绝对无法容忍的俗套元素。
4. **Turn 3: 候选小样与对比页交付**：
   - 绝不让用户仅凭抽象文字做决策。AI 依据选定方向与种子差异，快速产出 2–3 种轻量候选小样（仅限首屏核心区块），通过内置风格对比页（Pattern 7）并排交付供用户在真实浏览器中试玩与比对。
5. **Turn 4: 优势拼装与决胜锁定**：
   - 收集用户试玩反馈（如"A 的配色 + B 的布局 + C 的交互反馈"），融合提炼为生产级 POC 规范，用户确认后方可解锁工程编写与审查闭环。

## Pattern 4: 图像生成主动调用与凭据隔离模式 (Autonomous Image Gen & Key Isolation)

**When to use**: 界面设计中涉及 3D 核心主体、着色器特效、拟物微质感或真实环境光影，代码伪拟态无法达标时。

**How**:
1. **优先检测原生工具并主动生成**：
   - 检查当前环境是否内置生图能力（如平台的 `generate_image` 工具）。
   - 若具备，主智能体主动调用产出高保真图片资产（存入项目资源目录），严禁偷懒使用纯 CSS 径向渐变或通用占位图替代。
2. **能力缺失时的请求规约**：
   - 若当前环境无内置工具且确需生成资产，向用户主动发起请求：
     > "当前设计需要生成高精度的 [资产描述] 以实现顶级质感，检测到当前宿主环境缺少原生生图工具。请提供临时的 API Key。该凭据将严格保存于本地 `.env.agents` 中，仅用于本次素材渲染，绝不写入产品业务代码或提交至版本控制。"
3. **物理安全隔离流程**：
   - 创建或追加至根目录 `.env.agents`，并确保加入 `.gitignore`。
   - 编写独立的本地脚本调用 API 生成素材并落地为静态文件，严禁将 key 嵌入任何前端代码。

## Pattern 5: 循环悬浮微动效合成 (Looping Asset with Matting)

**When to use**: 为产品界面打造极具视觉冲击力的核心 Hero 资产（如旋转晶体、解构机械、液态折射体），纯 CSS 渲染无法满足质感需求时。

**How**:
1. 调用视频生成模型，提示词明确要求主体在页面相同底色上进行无缝循环物理运动。
2. 运行背景蒙版抠像算法，剥离底色，导出带有 Alpha 通道的循环 WebM 或序列帧。
3. 在前端将视频以 `<video autoplay loop muted playsinline>` 嵌入，跨越在区块分界线上打破单调布局。

## Pattern 6: 关键帧随动交互映射 (Keyframe Scroll Scrubbing)

**When to use**: 产品详情展示、硬件拆解或步骤引导页，希望用户通过滚动或拖拽获得电影级互动感。

**How**:
1. 用图像生成工具生成关键状态 0（收拢）与关键状态 1（展开）。
2. 调用具备物理插值能力的视频模型，将两张图作为首尾帧，渲染出 2-3 秒的平滑过渡片段。
3. 前端监听容器滚动百分比，解算为视频帧时间：
   ```typescript
   const progress = Math.min(Math.max(scrollOffset / totalDistance, 0), 1);
   videoElement.currentTime = videoElement.duration * progress;
   ```

## Pattern 7: 风格对比页生成与离线评审流 (Style Explorer Workflow)

**When to use**: 需要将 2–4 种方向的小样同屏展示供团队或用户直观对比与决策，或者对重构前后进行基线比对时。

**How**:
1. 在任务目录准备 `manifest.json` 与各候选文件（HTML/图片/本地 dev server 地址）。
2. 运行内置生成脚本：
   ```bash
   python3 <skill>/scripts/build_explorer.py manifest.json --output style-explorer.html
   ```
3. 打开生成的单个离线 HTML，在桌面和手机视口下并排比对块面节奏。
4. 用户点击方案卡片上的"选择"按钮，自动将决策文本复制至剪贴板并粘贴给 Agent。
